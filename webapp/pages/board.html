What is live here

This page is a view of the stream behind the Fleet, Alerts and Live monitor pages. For the bearing, this computer sends the raw motor current and vibration of each lift in turn, 4 s at a time, to the PYNQ-Z2. The board's ARM cores filter the signal, find the shaft speed and compute the spectra, and its FPGA runs the network. Every bearing status and bearing alert in this app comes from those results. The power supply, inverter and motor winding stages are computed on this computer.

The samples come from stored test-rig sensor data; no sensor is wired to the board. For every 4 s, this computer runs the same signal processing itself and checks the board's network input byte by byte, and that the FPGA's outputs match the bit-accurate model exactly.

The network deployed on the board was trained on data that includes this test rig, so these verdicts show the board working. They do not measure how it would do on a machine it has never seen. The About page gives that figure, measured on bearings withheld from training.
